# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-09-19

### Added

- Initial release of `@superutils/expo-binary-module`.
- Run and manage long-running native binaries on Android.
- Android foreground service support.
- Configurable environment variables for native binaries.
- Persistent auto-start, auto-pause & resume configuration.
- Startup detection and timeout handling.
- Configurable foreground service notifications.
- Notification actions and URI handling.
- Native binary stdout monitoring and event handling.
- InterProcess Communication (IPC): Android notification and event from binary stdout log.
